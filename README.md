# Avoid overengineering

A short skill for AI coding assistants that keeps changes focused on what you asked for.

It encourages assistants to reuse existing code, avoid unnecessary features and confirmation steps, question assumptions during reviews, and test useful behavior. Required safeguards stay in place. Features with no clear purpose are removed along with the code and checks that support them.

Use [SKILL.md](avoid-overengineering/SKILL.md) for coding, fixes, reviews and test changes. Copy the `avoid-overengineering` folder into your assistant's skills directory, or provide the file as reusable instructions.
